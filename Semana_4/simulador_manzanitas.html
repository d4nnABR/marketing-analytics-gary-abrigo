Medir: tapar una compra y adivinar

A cada cliente se le tapa una compra que sí hizo. Cada método intenta adivinarla con lo demás. Si la compra tapada está entre las primeras k sugerencias, es un acierto (hit@k).

k = sugerencias que se le muestran a cada cliente

Cliente por cliente

Con honestidad

Son pocos datos. Solo hay 14 clientes evaluados: un cliente más o menos mueve cada barra unos 7 puntos. Si dos métodos quedan cerca, no se puede decir cuál es mejor. Con otro reparto de las compras tapadas el orden podría cambiar.

Acertar no prueba que la recomendación cause la compra. Un cliente que ya iba a comprar Crema con su Fresa también cuenta como acierto, aunque no hubiera hecho falta sugerírsela. Para saber si recomendar vende más, hay que hacer un test A/B: a unos clientes se les muestra la sugerencia y a otros no, y se comparan las compras.
